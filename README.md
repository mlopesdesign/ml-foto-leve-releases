# ML Foto Leve — instalador e atualizações

Fotos bem menores, mesma aparência. Otimizador perceptual de fotos para Windows, da **ML Lopes Design**.

## Instalar

Baixe o **ML-Foto-Leve-Setup-vX.Y.Z.exe** da [versão mais recente](https://github.com/mlopesdesign/ml-foto-leve-releases/releases/latest) e execute.
Não é preciso ser administrador. Requisitos: Windows 10 ou 11 (64 bits).

## Atualizar

O próprio programa avisa quando há versão nova e se atualiza com um clique
(Configurações → Atualizações e novidades).

---

Este repositório contém apenas os arquivos de distribuição. Cada release traz:

| Arquivo | Uso |
|---|---|
| `ML-Foto-Leve-Setup-vX.Y.Z.exe` | Instalador |
| `resources.neu` | Pacote da atualização automática |

Os SHA-256 de cada arquivo estão nas notas da release.
